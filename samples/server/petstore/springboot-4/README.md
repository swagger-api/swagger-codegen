# Swagger generated server

Spring Boot 4 Server (Spring Framework 7, Jackson 3)


## Overview
This server was generated by the [swagger-codegen](https://github.com/swagger-api/swagger-codegen) project.
By using the [OpenAPI-Spec](https://github.com/swagger-api/swagger-core), you can easily generate a server stub.
This is an example of building a swagger-enabled server in Java using the SpringBoot framework.

Requirements: Java 17+ (Spring Boot 4 needs Java 17 or newer).
The generated API interfaces carry default methods (the `java8` option is always on for this library).
JSON (de)serialization uses Jackson 3 (`tools.jackson.*`); Jackson annotations stay on `com.fasterxml.jackson.annotation`.

The underlying library integrating swagger to SpringBoot is [springdoc-openapi](https://github.com/springdoc/springdoc-openapi)

Start your server as an simple java application  

You can view the api documentation in swagger-ui by pointing to  
http://localhost:8080/  

Change default port value in application.properties
